# Echo Copy Puzzle

**Echo Copy Puzzle** — это 3D-игра-головоломка на Unity, в которой игрок использует механику **«Эхо-копия»** и переключаемые способности для прохождения испытаний с физикой, полярностью и боевой турелью.

## Функционал игры

В проекте реализованы следующие ключевые механики:

- **Способность «Эхо-копия»**: создание временной копии физического объекта.
  - Дальность: **5 м**
  - Время жизни копии: **8 секунд**
  - Лимит: **1 копия** (с возможностью расширения до 2)
- **Обратная полярность копии**: эхо-объекты взаимодействуют с особыми поверхностями и активаторами.
- **Переключение способностей (`F`)**:
  - `Echo Copy` — создание копии (`E`)
  - `Grab` — захват/перенос объекта (`E` взять, `E` отпустить)
- **Физические головоломки**:
  - двойной вес на плите (оригинал + копия),
  - временный мост через разрыв,
  - инвертированные активаторы.
- **Отвлечение турели**:
  - турель приоритетно переводит внимание на эхо-источник.
- **Боевая комната с турелью**:
  - мини-ракеты, урон по игроку,
  - HP-индикатор в зоне боя,
  - респавн при смерти и при падении ниже порога.

## Описание игрового процесса

Игрок проходит серию комнат, где каждая развивает механику эхо-копий:

1. **Комната 1 (двойной вес)**  
   Нужно создать копию ящика и поставить оба объекта на тяжёлую плиту, чтобы открыть дверь.

2. **Комната 2 (полярность и временный проход)**  
   Эхо-копия используется для взаимодействия с инвертированным активатором и преодоления участка уровня.

3. **Комната 3 (турель и выживание)**  
   Игрок проходит коридор за турелью, избегая огня, используя укрытия и отвлечение турели эхо-копией.

Игра построена на комбинации физики, тайминга и управления вниманием противника.

## Управление

- `WASD` — движение  
- `Mouse` — обзор  
- `Left Shift` — рывок  
- `F` — переключение способности (`Echo Copy` / `Grab`)  
- `E` — использование текущей способности  
  - в `Echo Copy`: создать копию
  - в `Grab`: взять/отпустить объект

## Структура проекта

Основные скрипты находятся в:

- `Assets/SonicShaper/Scripts/Player` — игрок, способности, здоровье
- `Assets/SonicShaper/Scripts/Puzzles` — двери, плиты, турель, боевые зоны
- `Assets/SonicShaper/Scripts/Echo` — полярность, эхо-копии, эхо-активаторы
